# VictoryInfra Website

Static website for VictoryInfra, a Philippine infrastructure and construction
company — a member of the Victory group.

- `index.html`, `css/`, `js/` — the site itself (no build step required)
- `.github/workflows/deploy-pages.yml` — GitHub Pages deployment (manual
  trigger until Pages is enabled for this repo)

To preview locally, open `index.html` in any browser.
